# Lodash Playground with CDN

This project provides a simple playground to experiment with Lodash functions directly in the browser using a CDN.

## Features
- Load Lodash from a CDN
- Try out Lodash functions interactively
- Simple and minimal UI for quick testing

## Getting Started
1. Open the HTML file in your browser.
2. Use the input area to write and test Lodash code.

## Requirements
- Internet connection (to load Lodash from CDN)
- Modern web browser

## Usage
- Type Lodash code in the editor and see the results instantly.
- Example:
  ```js
  _.chunk(['a', 'b', 'c', 'd'], 2)
  // => [['a', 'b'], ['c', 'd']]
  ```
